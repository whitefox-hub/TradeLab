        A trend you read in the news is a trend everyone else has read too, so it cannot say whether to hold something — that part is priced before it can be acted on (§11.3). What it can say is how much: it scales a position up to half either way, never creates one, and never changes a sign. Applied to an empty book it is still empty. Whether it helps at all is untested, which is why each run is reported against the same run without it.

        The index is a vendor number and is stored where it can be looked at, not where a study reaches for it. Its method is not auditable and it is composed partly of data already collected here, so §11.4 builds the market state index in-house instead. What is honest about it is the stamp: one value per UTC day, published at that day's midnight and never revised, so nothing here can be read before it existed. The chart the vendor draws beside it is a time series, and those belong in Grafana rather than on this page.
