Algorithm

What the system does, in the order it does it.

Each step carries the rule that has to hold when it runs and, where there is one, what it cost to learn that the rule was needed. That pairing is deliberate: a rule with no story behind it reads as a preference, and the next person reorders it. Most of the marked ones were real defects here, found by tests built so that the wrong behaviour produces a visibly wrong answer rather than a plausible one.
